Self-hosted, Latin-subset WOFF2 files for Casa Scripta pages.

- Inter — SIL Open Font License 1.1, https://github.com/rsms/inter
- Cormorant Garamond — SIL Open Font License 1.1, https://github.com/CatharsisFonts/Cormorant

These files are subsets of the original fonts, for serving this site only.
Cinzel was dropped so the site loads two families (Inter + Cormorant Garamond). Wordmarks and labels use Cormorant with the existing letter-spacing.
